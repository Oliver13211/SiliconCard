卡牌效果预览

P2-UI2 · 本期亮点
  • 点卡出预览面板：白话解释——EffectSpec 步骤翻译成人话（"指定任意角色造成 3 点伤害"）
  • 沙箱迷你演示：initGame 起固定演示局面，脚本打出这张卡，事件流驱动演示动画循环播放
  • 卡池扩充自动获得预览——零逐卡内容成本
看法：这是无头引擎的杀手级应用。效果引擎算、动画引擎演、翻译规则化——三层全是既有资产的新组合，没有一处手工维护面。

对战回放 + AI 复盘

P2-INF1 · P2-UI3 · P2-QA1
  • 复用 core 现成基建：ReplayRecording + canonicalJson + FNV-1a stableHash（黄金回放在用）

看法：全期 ROI 最高的一块——录制即复现是确定性引擎的天然特权，竞品要搭录制回放系统，我们只需要把已有序列化接上 UI。

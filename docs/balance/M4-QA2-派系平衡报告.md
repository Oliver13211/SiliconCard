# M4-QA2 · 派系平衡报告

> 任务：M4-QA2 平衡管线（CLI 自对弈批量跑分 → 派系胜率报告 → 数值调整迭代）。
> 执行：qa-balance（WF-BALANCE）。日期：2026-10-06。
> **验收结论：7 套预组卡组派系胜率极差 5.9pp（< 10pp 达标），三种子基线复核均达标。**

---

## 1. 管线与复跑方式

批量对局矩阵新增于 `packages/ai`（`runDeckMatchup` / `runFactionBalance`，`src/matchup.ts`），跑分入口为 cli 扩展命令：

```bash
# 默认规模：7 套预组卡组两两循环，每配对每方向 150 局 + 镜像每方向 50 局（约 30 秒）
yarn workspace @siliconcard/cli bench
# 指定规模与机器可读 JSON 输出（本报告数据即此命令产出）
yarn workspace @siliconcard/cli bench --games 150 --mirror 50 --seed 20261006 \
  --json docs/balance/data/m4-qa2-final-seed20261006.json
```

- 对局驱动复用 `runSelfPlayGame`（三重护栏：动作成员校验 / RuleError 兜底 / 动作上限），双方 AI 全程只经 `createAiPlayer` 公开接口（`getLegalActions` + `viewFor`），无任何完整 state 读取。
- 卡牌出场 / 胜率贡献统计来自引擎公开事件流（`CARD_PLAYED` / 胜负），`runSelfPlayGame` 新增可选 `collectEvents`（缺省关闭，M1 验收路径零开销不变）。

### 统计口径（重要）

| 口径 | 说明 |
| --- | --- |
| 先手偏差处理 | 引擎 P1 固定先手（`FIRST_PLAYER`）。每配对**同一颗种子双向各跑一局**（A 先手 + B 先手），先手优势在配对内对称抵消；派系胜率因此不受先手污染 |
| 镜像局 | 同卡组互打，只用于直测先手胜率与卡牌出场统计，**不计入派系强度极差** |
| 派系胜率 | `(胜 + 0.5×平) / 局数`，仅统计跨卡组对局（每卡组 6 对手 × 300 局 = 1800 局） |
| 极差 spread | 派系胜率最大 − 最小（百分点） |
| 卡组数量口径 | 现役 7 派系 90 卡，**每派系一套预组卡组共 7 套**（neutral 全能套即其中之一；任务背景中的「8 套」与仓库实际不符，以此为准） |

## 4. 卡牌出场率 / 胜率贡献（摘要）

口径：`playRate = 打出过该卡的对局数 / 该卡所在卡组参与对局数`；`playedWin = 打出该卡的执方胜率`。完整数据见 `data/m4-qa2-final-seed20261006.json` 的 `cards` 数组。

- **高出场高贡献**（数值健康）：`qualcomm-snapdragon-x-elite`（playRate 60.3% / playedWin 58.7%）、`apple-m1-ultra`（62.5% / 55.5%）、`intel-i9-9900k`（58.9% / 55.4%）——各派系传说位/标杆位均在场且有存在感。
- **低出场**（出场 < 15%，观察项，未动）：`nvidia-rtx-5090d`（10.9%）、`nvidia-multi-frame-gen`（11.6%）、`amd-afmf`（10.1%）、`neutral-990-pro`（12.8%）——多为「效果不差但 AI 评估不倾向打」的抽牌/延后型卡，与启发式评估口径有关（见 §6-3）。
- neutral 共享填充卡在 R4 后 playedWin 约 48%–58%（电竞椅 57.8%、G502 53.4%），作为 7 卡组共用骨架已到「不拖累、不主导」的预期位置。

## 6. 偏差、测量盲区与遗留观察（如实报告）

1. **先手 +9pp 是体验层最大偏差**：对称设计让平衡统计不受污染，但玩家对局里先手优势真实存在。任何引擎级补偿（后手增益/换边）走 WF-ENGINE，本任务只记录不动。
2. **neutral 全能套仍居末位（47.0%）**：作为「装机佬标配」参考卡组，其上限受制于卡池定位（无传说级威胁点、回复/终结手段少）。数值已抬到带内；若要求它也具备争顶强度，需要卡组构成调整（换入更强中立卡）或中立派系技能（清灰）强化——后者在 core builtin，超出本任务授权。建议作为 M4 后续观察项而非阻塞项。
3. **AI 启发式对 aura/配件（0/1 身板）评估偏低**：B650M/双 BIOS/水冷等光环卡的 playedWin 与出场率系统性低于其理论价值，弱点卡组（neutral/amd）受影响最大。本次以卡牌数值绕行达标；`packages/ai` 的 `evaluate.ts` 调优是独立任务（注意：评估器改动会整体改变跑分口径，需重新基线）。
4. **组间克制纹理**：apple × nvidia（36.3%）、apple × arm（38.7%）、arm × nvidia（59.0%）。在极差达标前提下保留，属于可读的 RPS 关系；若未来收紧到 <5pp 需要针对配对特化调整，不建议。
5. **低出场卡群**（§4）：多数是「效果结构不吸引 AI」而非纯数值问题；列观察，不做数值硬抬（会把 playRate 抬上去但胜率贡献未必为正）。
6. **镜像局 aWins/bWins 口径**：见 §2 先手偏差节；后续若要让镜像配对记录也可读，可在 bench JSON 里把镜像行的 aWins/bWins 换成 seat 口径（当前以文档说明代替代码改动）。
7. **任务背景与仓库事实的偏差**：任务描述「8 套卡组」，实际 7 套（7 派系各一套）；「三新派系数值初稿」确实全面偏强/偏弱（qualcomm 初稿 69.8% 的主要贡献卡全部来自 M4-CNT5 新卡），本次已系统性校正。
